# 圖面註冊表（Drawing Register）— intake 半的地基

這個資料夾是「上游 intake」這一半的種子。目的：把散落的圖檔變成一份**可被指認的索引**，讓萃取器能把「91 3F 茶水間」這種話對應到一個真實檔案。

- `register.csv` — 圖面註冊表（一張圖一列）。**你手填的主要對象。**
- `glossary.json` — 詞彙表：棟別別名、專業代碼。跨圖套用的規則型別名。
- 本檔 — 怎麼填、為什麼這樣設計、怎麼接到後面。

---

## 為什麼手填，卻不是白工

你現在手填的每個欄位，**都對齊「圖面標題欄（title block）自動能讀出什麼」**。所以：

- **現在**：你手填一份真實資料 → 當萃取評測的標準答案 + 摸清自動化該解什麼。
- **Move 1**：agent 蓋一支掃描器，讀資料夾 + 標題欄，自動草擬這張表；你只校正。
- **產品版**：客戶把資料夾一指 → 系統幾分鐘草擬 register → 客戶校正。這就是「無痕導入」。

手填 = 手動版；未來 = 自動版。同一張表，同一組欄位。

## 每欄的來源（這是重點）

| 欄位 | 中文 | 來源 | Move 1 能否自動 |
|---|---|---|---|
| `drawing_no` | 圖號 | 標題欄 / 檔名 | ✅ 自動（唯一鍵） |
| `title` | 圖名 | 標題欄 | ✅ 自動 |
| `project_id` | 專案號 | 標題欄 / 資料夾 | ✅ 自動 |
| `building` | 棟別 | 標題欄 / 圖名 | ⚠️ 半自動（可能要對詞彙表） |
| `floor` | 樓層 | 圖名 | ⚠️ 半自動（大樣/系統圖可能空白） |
| `discipline` | 專業 | 圖號前綴（A/S/E/M/P/F） | ✅ 自動 |
| `current_ver` | 目前版次 | 標題欄 / 檔名 | ✅ 自動 |
| `cad_path` | CAD 路徑 | 資料夾掃描 | ✅ 自動 |
| `pdf_path` | PDF 路徑 | 資料夾掃描 | ✅ 自動 |
| `aliases` | 別名 | **人腦 / 使用學習** | ❌ 這格是你的價值 |

**`aliases` 是整份表唯一「機器讀不出來」的欄位**——它是「工地實際怎麼稱呼這張圖」。用 `|` 分隔多個，例如 `91 2F|管理大樓二樓|2F平面`。這一欄是萃取準確率的天花板，也是未來靠 `corrections.jsonl` 隨用隨長的東西。冷啟動先手動放幾個，之後系統自己養肥。

## 對應的兩個層次（別搞混）

工程圖是「一張平面圖含很多房間」。所以對應有兩層：

1. **圖面層**（register 負責）：`棟別 + 樓層 + 專業` → `drawing_no`。
   例：「91 2F（建築）」→ `A-201`。
2. **位置層**（App 的座標標註負責）：房間（廁所 / 茶水間 / 電梯廳）是**落在該張圖上的一個點**，不是另一張圖。
   例：「2F 廁所 東移 10 公分」→ 圖 `A-201` + 圖上一個標註位置。

所以 register **不需要**為每個房間建一列；房間名交給萃取當「位置線索」，對應到圖後由人在圖上點位置（那個動作又回饋進 `corrections.jsonl`）。

## 怎麼填

1. 用 Excel / Google Sheet 開 `register.csv`（UTF-8）。
2. 現有三列是 sample 資料的範例，照樣式**換成你一個真實專案**的圖。
3. `aliases` 想不到就先放 1~2 個最常見叫法，不用求全。
4. `floor` 遇到大樣圖 / 系統圖 / 配置圖沒有明確樓層 → 留空，正常。
5. `glossary.json` 的 `buildings` 換成你真實專案的棟別與代號。

覆蓋率抓「這個專案目前進行中的圖 > 90%」就夠開始，不用一次填完歷史所有圖。

## 填完之後接到哪

這份表是 Move 1–2 的輸入：

- **Move 1**：agent 把 register 正規化成 `register.json`，並蓋掃描器自動草擬（未來取代 `server.py` 那條 regex 猜圖號）。
- **Move 2**：萃取器把信件 → request，用 `glossary` + `register` 把別名解析成 `drawing_no` + `pdf_path`，再對 `synthetic-data-gen/output/ground_truth.jsonl` 打分。
- **Move 3**：萃取輸出對齊 App 的 `create_request` payload（`server.py` 約 338 行），真信 → 真任務 → 已對應到真圖。
