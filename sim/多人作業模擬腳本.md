# 單機多人作業模擬 — 操作腳本

在**同一台電腦**上，透過切換「我的名字」扮演不同角色，把多人協作流程完整走一遍。
資料全部來自 `synthetic-data-gen/` 的合成信件，不碰任何真實機密文件。

---

## 這是什麼、為什麼這樣設計

目前 ArchiHub 是單機、單一設定身分（詳見 [升級路徑 doc](../docs/01.meetings/2026-07-22-單機到內網多人升級路徑-v0.1.md)）。
在真正的內網多人版做好之前，可以用**「一個人切換身分」**把多人劇本演一遍——這對驗證狀態機與 UI 已經足夠。

`run_sim.py` 幫你把舞台佈置好：從信件自動產生一批任務，並用真實狀態機驅動成
**「一個進行到一半的專案」**——有人剛派工、有人正在改、有人待確認、有人被退回、有人已進版。
你接手後，只要切換身分就能從每個人的視角繼續操作。

---

## 一鍵啟動

```bash
python sim/run_sim.py            # 8734 沒開會自動幫你啟動 server
# 重跑（清掉舊的 SIM 資料）：
python sim/run_sim.py --reset
```

跑完會在終端機印出**看板**（有哪些 REQ、各自的 designer / requester、目前狀態）。
**以那份印出的清單為準**操作，下面的步驟用角色來描述。

開 <http://localhost:8734>，右上角會看到專案已經是 **「SIM · 多人作業模擬」**。

> 切換身分：右上「⚙ 設定」→「我的名字」填入要扮演的人 → 儲存。
> 「🔧 待辦作業」= 我是該任務的 designer 且待處理；「👁 待我確認」= 我是 requester 且對方已提交。

---

## 開場的看板長怎樣（run_sim 佈好的狀態）

| 狀態 | 筆數 | 意思 |
|---|---|---|
| 🔴 剛萃取・待接受 | 6 | 從信件自動建立、還沒人動 |
| 🔴 已接受・本地編輯中（🔒 鎖定） | 2 | designer 已取出 CAD 正在改 |
| 🟡 已提交・待確認 | 2 | designer 改完出 pending PDF，等 requester 核 |
| 🔴 退回重修中 | 1 | requester 看了不符，已退回、附原因 |
| 🔴 任務被拒・待釐清 | 1 | designer 覺得需求不清，已回信要求釐清 |
| 🟢 已進版結案 | 2 | 已確認、進新版流水號、通知全員 |

另外收件匣還留著 **26 封未處理信件**，供你練習「萃取 → 建單」。

## 導覽腳本：把五種互動各走一次

### ① 設計端：接任務 → 改 → 提交（🔴→🟡）
1. 設定「我的名字」= 看板上某個 **designer**（阿勳 或 小柯）。
2. 進「🔧 待辦作業」，點一筆「剛萃取・待接受」的紅燈任務。
3. 按 **「接受任務・前往修改」**→ 系統嘗試開 CAD 本地副本（此機無 CAD 會提示，正常）。
4. 按 **「完成並提交」**→ 自動出 `_pending_` PDF，任務轉 🟡，回到 requester 手上。

### ② 需求端：確認進版（🟡→🟢）
1. 設定「我的名字」= 剛才那筆任務的 **requester**（看板上有寫）。
2. 進「👁 待我確認」，點該筆黃燈任務。
3. 按 **「🧾 檢視提交的 PDF」**看 pending 圖。
4. 按 **「✓ 確認符合要求 → 正式進版」**→ 進新版流水號、pending 作廢、版本歷史多一筆。

### ③ 需求端：退回重修（🟡→🔴，帶問題標註）
1. 一樣以某筆黃燈任務的 **requester** 身分。
2. 按 **「↩ 退回重修」**→ 在圖面上**點出問題位置**（紫色 ↩ 標記）+ 填退回原因 → 送出。
3. 切回該任務的 **designer**：詳情頁會看到紫色退回說明 + 圖上問題點；改完再「完成並提交」。
   （開場看板已有一筆「退回重修中」可直接看效果。）

### ④ 設計端：拒絕任務並回信（🔴）
1. 以某筆紅燈任務的 **designer** 身分，點該任務。
2. 按 **「⛔ 拒絕・退回詢問 Requester」**→ 填疑問 → 送出會**自動開回信頁**（mailto，帶原始需求引文）。
   （開場看板已有一筆「任務被拒・待釐清」可直接看效果；釐清後按「接受任務」即解除。）

### ⑤ 從收件匣自動萃取新任務（示範「信件 → 任務」）
1. 上方切到「📥 收件匣」，會看到 26 封未處理信件（📧 信件 / 📝 筆記兩種來源）。
2. 任選一封按 **「✨ AI 萃取 → 產生 Request」**（目前為規則式解析，欄位可改）。
3. 選對應圖面、指派 designer、確認建立 → 新任務出現在該 designer 的「待辦」。
4. 切成那位 designer，就能接續 ① 的流程。

---

## 小提醒

- **這是模擬**：CAD 檔是占位檔（開不了真 CAD 是正常的）；PDF 是自動生成的示意圖。目的在跑通**流程與多人視角**，不是真的改圖。
- **身分可造假**：現階段「我的名字」隨你填、動作的 actor 就是它——這正是單機信任制的現況，也是為什麼升級路徑裡 **S2 登入**要處理「身分不可造假」。
- **想重來**：`python sim/run_sim.py --reset`。
- 生成的資料都在 `sim/project/` 與 `data/sim/`（皆不進版控），不影響你原本的 928816 專案。切回原專案：右上專案下拉選單即可。
