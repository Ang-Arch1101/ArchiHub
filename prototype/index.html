⇄ 架構邏輯：GitHub 對照表

軟體工程用 Git 管程式碼，我們用同一套邏輯管圖面。
GitHubArchiHub
Repository中央檔案庫（CAD 源檔 + PDF 出圖）
Issue / Pull Request圖面修改 Request（🔴 紅燈建立）
Clone / Pull「前往修改」→ 自動建立本地副本（local copy）
Commit / Push「完成並提交」→ 存檔 + 自動出 PDF + 推回中央庫（🟡 黃燈 Pending）
Review / Merge發 Request 者確認符合要求 → 正式進版（🟢 綠燈）
Commit history進版流水號 + 歷史軌跡（designer / approver 都記錄）
Fork（未合併分支）編輯中版本：有流水號，但不取代中央檔
NotificationConfirm 後自動通知所有人：舊版已被取代
